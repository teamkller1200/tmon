# tui-gpumonitor

Rust + ratatui 製のターミナル・システムモニタ。Windows タスクマネージャー相当の「パフォーマンス」タブと「プロセス」タブを、端末の中だけで提供します。

## 機能

### Performance タブ
- CPU 使用率（全体のバー + 各コアごとのバー）
- メモリ使用量 / 合計（スワップ含む）
- ディスクの読み書き速度（バイト/秒）
- ネットワークの送受信速度（ループバックを除く全インターフェースの合算）
- GPU 使用率 / VRAM / 温度 / 電力 / ファン回転（`nvidia-smi` がある場合のみ）
- CPU と GPU の 60 秒推移グラフ（縦軸 0〜100%、横軸 -60s〜now、目盛付き）

### Processes タブ
- プロセス一覧: 名前 / PID / CPU% / メモリ / ディスク読み書き
- ソート（列を切り替え、昇順・降順の反転）、名前と PID による絞り込み
- ホイールで 1 行スクロール、行のクリックで選択
- `x` で選択中のプロセスを終了。中央のモーダルで確認し、`y` を押したときだけ実行します
  - PID 0（System Idle Process）/ PID 4（System）/ このモニタ自身は拒否
  - 確認した時点のプロセス開始時刻を保持し、終了の直前に再取得して照合するため、PID が再利用されていた場合は中止します

## 操作方法

| キー | 動作 |
| --- | --- |
| `Tab` / `→` / `l` / `←` / `h` | タブを切り替え（タブ見出しのクリックでも可） |
| `j` / `↓` / `k` / `↑` | 選択行を 1 つ移動 |
| `PageDown` / `PageUp` | 選択行を 10 移動 |
| ホイール / 行クリック | 選択行を 1 つ移動（Processes タブのみ） |
| `s` | ソート列を切り替え（Name → PID → CPU → MEM → Disk → Name） |
| `r` | 昇順 / 降順を反転 |
| `/` | 絞り込み入力（`Enter` / `Esc` で閉じる、`Backspace` で削除） |
| `x` | 選択中のプロセスを終了（確認モーダル、`y` で実行 / それ以外は中止） |
| `q` | 終了 |

## ビルド

Rust 1.95 以降（edition 2024）が必要です。

```sh
cargo build --release
target\release\tui-gpumonitor.exe
```

## 動作環境と制限
- Windows 10 / 11 を対象（CPU 計測とプロセス終了は `sysinfo` の Windows 実装に依存）
- 端末は 80x24 以上を推奨。狭い場合も panic せず、収まる範囲だけを描画します
- GPU 情報は NVIDIA の `nvidia-smi` が PATH にある場合のみ。無い場合は GPU パネルに unavailable と表示します
- CPU% はコア数で正規化した 0〜100 です（全体もプロセス単位も同じ尺度。タスクマネージャーと同様）
- 履歴は 1 秒間隔で 60 サンプル（60 秒分）を保持します
- プロセスごとのネットワーク I/O は `sysinfo` では取得できないため未対応です
- マウス操作のためマウスキャプチャを有効にします。終了時（エラー終了時も含む）に元へ戻します
